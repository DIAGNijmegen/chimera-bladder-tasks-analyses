## Code repository for CHIMERA Challenge Task 2 and 3: Response Subtypes Classification and Progression Survival Prediction in Bladder Cancer Patients using Multimodal Datasets

This repository contains the source code and evaluation pipelines used in the challenge paper with title: "CHIMERA Challenge Task 2 and 3: Response Subtypes Classification and Progression Survival Prediction in Bladder Cancer Patients using Multimodal Datasets". 

#### Folder structure and the respective sections in the manuscript
- 1_4_robustness_and_reduced_models
    - Section 3.3. Robustness
    - Section 3.6. Reduced models - removing modality-overlapping variables
- 2_3_structured_data_missing_values_variables
    - Section 3.4. Structured data: missing values
    - Section 3.5. Structured data: missing variables
- 5_error_analysis
    - Section 3.7. Error analysis

Note: This repository is currently supporting an on-going peer-review process. Source code and documentations are being uploaded and structured gradually as the review progresses.
