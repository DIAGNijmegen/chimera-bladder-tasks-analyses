This repository contains the source code and evaluation pipelines used in the challenge paper with title: "CHIMERA Challenge Task 2 and 3: Response Subtypes Classification and Progression Survival Prediction in Bladder Cancer Patients using Multimodal Datasets". 

Note: This repository is currently supporting an on-going peer-review process. Source code and documentations are being uploaded and structured gradually as the review progresses.
